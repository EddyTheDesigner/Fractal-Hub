# Asset attribution

All shipped Fractal Hub code, presets, custom palettes and assets are original work licensed under the included MIT license.

| Asset | Origin |
| --- | --- |
| Preset settings and custom palettes | Original Fractal Hub recipes; no vendor preset files used |
| Panel icons and logo | Original geometric ScriptUI drawings |
| Preview frames | Generated with EffectCraft 0.14.0 from the original recipes |
| Gallery screenshot and preset preview sheet | Original procedural media displayed by Fractal Hub |

EffectCraft is the independent open-source host ([source](https://github.com/storytold/effectcraft)); its executable is not bundled. Fractal Noise Browser and GradientHub were visual and workflow references. No vendor thumbnails, proprietary presets, implementation code or Adobe assets are included.
