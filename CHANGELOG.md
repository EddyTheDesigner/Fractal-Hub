# Changelog

## 1.1.0

- Reauthored 108 presets with greater differences in form, detail, contrast and composition.
- Includes 54 grayscale textures and 54 colored looks.
- Adds editable native distortion, relief and original Colorama palettes to selected recipes.
- Replaces and saves complete recipes while preserving unrelated effects.
- Stabilizes Turbulent Displace across effect instances for reproducible results.
- Includes 432 antialiased preview frames rendered from the actual recipes.
- Retains the gallery layout, icon controls, hover names, favorites and animation options.
- Provides one universal JSX release with Windows, Linux and macOS installation guides. Windows was tested with EffectCraft 0.14.0; Linux and macOS native execution remains unverified.

Close the existing panel, install the new JSX, then reopen it. Favorite IDs and existing saved user presets remain compatible. Existing project effects change only when a new recipe is applied.
